# 🏠 StayNest

StayNest is a full-stack property rental web application where users can explore available homes, view property details, register their own properties, manage listings, and save their favorite stays.

The project was built to practice and demonstrate full-stack web development using **Node.js, Express.js, MongoDB, Mongoose, EJS, and JavaScript**.

## 🚀 Live Demo
🔗 https://staynest-world.vercel.app/

## 🚀 Features

* 🔐 User registration and login
* 🏠 Browse available properties
* 🔎 View detailed property information
* ➕ Add new property listings
* ✏️ Edit property listings
* 🗑️ Delete property listings
* ❤️ Add properties to favorites
* 📷 Upload property images
* 📱 Responsive user interface
* 🔒 Session-based authentication
* 💾 MongoDB database integration
* ⚡ Server-side rendering with EJS
* 🛡️ Form validation and error handling

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/StayNest.git
```

### 2. Open the project

```bash
cd StayNest
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file:

```env
MONGODB_URI=your_mongodb_connection_string
SESSION_SECRET=your_session_secret
```

Add any other environment variables required by your application.

### 5. Start the application

For development:

```bash
npm run dev
```

or:

```bash
npm start
```

Then open:

```text
http://localhost:3004
```


## 🔐 Environment Variables

Do not upload your real `.env` file to GitHub.

Add `.env` to `.gitignore`:

```gitignore
node_modules/
.env
uploads/
```

Create an `.env.example` file instead:

```env
MONGODB_URI=
SESSION_SECRET=
```
